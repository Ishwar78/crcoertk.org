# Chhotu Ram College of Education — Premium React Website

## Stack
- React + Vite
- React Router
- React Icons
- Montserrat typography
- Dedicated JSX + CSS for every page
- Dedicated Navbar.jsx/Navbar.css and Footer.jsx/Footer.css
- No data.js/common page CSS file
- All local images live in `public/images`

## Run
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm run preview
```
